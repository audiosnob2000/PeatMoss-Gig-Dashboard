# Peat Moss Gig Dashboard — Feature Walkthrough

*A guided tour to run through with testers before handing them the feedback questionnaire.*

1. **Gig Overview**
   Upcoming shows with date, time, location, and pay at a glance.

2. **Gig Detail Page**
   All the details on one gig in a single view.

3. **One-Tap Google Maps**
   Tap the address, opens directly in Maps — no copy/pasting.

4. **Home Button + Return Trip Tracking**
   Navigates home after a gig AND auto-logs the return mileage.

5. **Automatic Mileage Tracking**
   Per-trip logging, editable/deletable if something logs wrong.

6. **Gig Reminders**
   Automatic notifications the day before AND the morning of each gig, so nobody forgets.

7. **Setlists**
   Build and view the song order for each gig.

8. **Gear/Packing Checklists**
   A checklist per gig so nothing gets left behind.

9. **Chart Library (under Songs tab)**
   - Search by title, key, or vibe/tag
   - Add charts via photo, PDF, or typed chords/lyrics
   - Photo charts have a rotate toggle (portrait/landscape) that remembers orientation per song

10. **Chart Sharing**
    Share a single chart directly to band members in-app.

11. **Stage Plot in Settings**
    Preview, copy, or share with a venue/sound person.

12. **Shareable Schedule**
    Share the band's upcoming gig schedule with people outside the app (venue, spouse, fill-in player) without giving them full access.

13. **Calendar Sync**
    Gigs pull automatically from the band's shared Google Calendar.

14. **Band Messaging**
    Message the band directly in the app instead of a separate group chat.

15. **Weekly "What's New" Update**
    Every Monday, a short summary of whatever features shipped that week gets posted automatically as a band message/banner — no one has to go looking for a changelog.

---

**Note for Jon:** Chart Library data is stored locally on-device for now (no cloud sync yet) — worth mentioning so no one's surprised charts don't show up on a different phone.
